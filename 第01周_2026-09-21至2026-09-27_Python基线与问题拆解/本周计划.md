# 第 1 周计划：Python 基线与问题拆解

## 本周目标

1. 保留一次真实的独立编程基线，不追求第一次就完成。
2. 学会把题目写成“输入—输出—规则—步骤”。
3. 复习列表、字典、循环、条件和函数，并用于新问题。
4. 建立 10～15 分钟独立尝试和分级求助习惯。

## 本周产出

- `sales_baseline.py`：第一天的原始版本和修订版本。
- 至少 6 道小练习。
- 一份周测和复盘。

## 主资源

- FCC 已学章节，只在需要回顾时使用。
- Exercism Python 基础练习。
- Python 官方中文教程用于查询。

## 本周限制

- 不学习 FCC 后续新 OOP 内容。
- 不直接让 AI 输出完整答案。
- 每次求助后必须关闭参考重新完成。
