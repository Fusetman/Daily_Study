# 第 2 周周测与复盘

## 周测规则

- 本次用于诊断，先用约 10～15 分钟闭卷写输入、输出和步骤，再独立实现；可以查 API 文档，记录查询，不复制旧解答或使用 AI 生成逻辑。预留 60～90 分钟，超时只记录实际用时，不直接判失败。
- 任务：读取一份 CSV 商品数据，检查必需字段，计算每个品类的库存金额并写出结果文件。
- 出题时明确一行代表一条库存记录，字段包含商品、品类、单价、库存数量；同一品类可以多行。单价乘库存量得到金额，负值、缺字段、非法数字按约定跳过并记录原因，空输入也须能输出可解释结果。
- 当前题与销售汇总结构接近，只用于检查完整流程；后续还需文本清洗或按编号去重等不同结构的迁移任务。
