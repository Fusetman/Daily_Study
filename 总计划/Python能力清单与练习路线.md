# Python 能力清单与练习路线

> 更新：2026-10-03。服务于数据分析主线；不是要求全部学完的 Python 大纲。当前状态依据已有每日记录，不代表本次重新测验过。

## 一、怎样判断掌握

- **待诊断**：记录没有充分证据，不等于从未学过。先做一道小题，不直接重上整章。
- **需提示**：看提示、仿照代码能完成，尚不能独立迁移。
- **独立完成**：能自行拆解、实现并验证新输入；可查 API 文档，记录查询内容。
- **迁移稳定**：隔次学习换题目或数据结构仍能独立完成，并解释边界和错误原因。

同一道题关闭答案后重写，只证明短期重现；隔天换题才补充迁移证据。已独立验证的内容不重复讲授，但可在综合题中抽查。代码运行通过与本人独立掌握分开记录。

## 五、进入 Pandas 时补什么

- 环境：确认解释器、建立虚拟环境、安装包，能区分终端命令与 Python 代码；记录版本与运行方法。
- Notebook：理解单元格执行顺序，重启内核后从头运行，避免靠残留变量得到结果。
- NumPy：数组、形状、类型、索引、布尔筛选、基础向量化与聚合；只学支撑当前数据处理的部分。
- 随后进入 Pandas 读取、筛选、缺失值、文本、日期、合并、聚合；不要求先完成一门完整 NumPy 课程。

Python 官方教程覆盖字符串、数据结构、函数、模块、异常和环境等主题，用于按需查询；它面向已有编程概念的人，不直接作为零基础教学顺序。[Python 官方教程](https://docs.python.org/zh-cn/3/tutorial/)。表格操作路线参考 [pandas 入门教程](https://pandas.pydata.org/docs/getting_started/intro_tutorials/)。

## 六、统一验收规则

周测用于诊断，不因某周得分直接判定整个阶段。Python 阶段验收分两部分：

1. 已完成项目：核对能运行、结果可复查、说明齐全，本人能讲清楚。
2. 陌生任务：先用约 10～15 分钟不看参考写输入、输出、规则和步骤，再独立实现。允许查标准库/API 文档，不看旧解答、不接受 AI 的任务拆解或代码提示；建议预留 60～90 分钟，超时记录实际用时，不自动判失败。时间仅用于观察熟练度。

评分以陌生任务为主；README 和解释可在实现后补充，不与编码抢限时：需求与口径 15 分、读取与校验 20 分、处理结果 25 分、函数组织 15 分、边界测试与调试 15 分、输出与解释 10 分。先给出具体预期行为，再评分；接受等价实现。

**核心门槛**：本人能自主拆出主要步骤，完成“读取—处理—输出”，正确处理正常数据及至少一个边界/无效输入，解释返回值和主要结果。需要别人提供核心结构或逻辑时，记为“需提示”，修正后的运行分数不能替代独立证据。

- **80 分及以上且核心门槛通过**：进入下一阶段，保留每周 Python 维护。
- **60～79 分且核心门槛通过**：有条件进入 Excel，在原复习预算内每周两次短补练，连续两周后换题复查；不能标记为 Python 阶段完全通过。
- **低于 60 分，或任一核心门槛未过**：安排 2～3 次学习补最弱环节，再换题验收；不按日历硬切阶段。若再次未过，缩小任务、检查前置知识和教学方式，不无限重复整套项目。

后续 Excel/SQL 等阶段沿用“分数 + 核心任务独立完成”的判定方式，但必须在开始时定义对应任务和评分项，不直接套用 Python 的题目。
