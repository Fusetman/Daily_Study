# 第 3 周计划：Python 基础补齐与数据清洗

> 2026-10-03 调整：以个人数据分析能力为目标。FCC 预算应用已移出任务和验收，不再安排账户类、转账或字符图表。

## 本周目标

1. 依据 Day13 诊断和 [能力清单](../总计划/Python能力清单与练习路线.md) 补 1～2 个最弱项，优先返回值、字符串清洗、排序与容器使用。
2. 完成两类结构不同的小任务：标签规范化与词频；报名记录按业务编号去重。不是销售汇总仅换名称或数字。
3. 把数据校验、清洗、统计和导出组合起来，并说明每条规则为什么存在。
4. 用陌生数据检验迁移；先教所需前置知识，不把未学 API 当成考试障碍。

## 候选顺序

需求与口径 → 字符串清洗 → 按编号去重 → 文件导出与边界测试 → 分组排序与核对 → 陌生数据验收。每日页只作候选素材；可以跳过已独立掌握项，或将较难任务拆成多次。日期不作为完成期限。

## 两类练习的边界

- 标签题：约定分隔符和大小写规则，清理首尾空格及空标签，统计频次和 Top N；同一条记录内是否去重必须先说明。
- 报名题：用模拟编号作为业务键，保留第一条有效记录；无效记录不占用编号，同名不同编号不能合并。保留被拒绝/重复记录及原因，不改写原始数据。
- 先用列表和字典验证几行，再接 CSV；不需要 Pandas、复杂类设计或图形界面。

## 本周产出

两类练习的代码、输入输出与边界验证；一段说明清洗规则、条数核对和本人求助位置的记录。每题先手算小样例，区分代码运行成功和独立完成。

## 求助与验收

学习时可以请求概念讲解和定位提示，之后换题验证；验收时允许查 API 文档，不复制旧答案，不让 AI 提供拆解或代码。具体规则见 [周测与复盘](周测与复盘.md) 和 [统一验收规则](../总计划/Python能力清单与练习路线.md)。
