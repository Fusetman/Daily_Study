# 数据分析学习规划目录

本目录采用“全年阶段路线 + 阶段验收 + 实际每日记录”的方式维护。预设每日主题和时长只是候选练习，不作为必须按日期完成的进度。

## 目录说明

- `总计划/数据分析学习计划_完善版.md`：全年目标、阶段路线、项目与求职节点、验收规则。
- `资源索引.md`：各阶段的主资源、练习平台和备用资料。
- `第01周_2026-09-21至2026-09-27_Python基线与问题拆解/`：第 1 周计划和每日记录。
- `第02周_2026-09-28至2026-10-04_Python函数与调试/`：第 2 周计划和每日记录。
- `第03周_2026-10-05至2026-10-11_预算应用/`：第 3 周计划和每日记录。
- `第04周_2026-10-12至2026-10-18_销售分析项目/`：第 4 周计划和每日记录。

## 使用方式

1. 开始学习时查看当前阶段目标和学习记录。教学前先梳理新知识点所需的前置知识，再对照记录确认哪些已经掌握；已记录为独立完成且验证通过的内容视为已掌握，无需重复教学。未记录、未完成或仍有疑点的前置知识，先用小练习补足并验证，再进入新知识点。学习记录是判断掌握情况的依据，不因计划日期到了就跳过前置知识。
2. 达到独立完成与验证标准后，可以继续下一项；没掌握就下次接着做。每天约 2～3 小时是可用时间参考，无须凑满。
3. 把成果和实际用时写进**实际学习日期**的子文件夹；跨天续做或提前学习其他主题时，在记录中注明来源，不改未来计划的日期。
4. 每周做一次小测与复盘；阶段结束时依据作品和独立完成情况决定下一阶段的任务。周日原则上休息或轻量复盘。
5. 以后新增阶段只写目标、候选练习和验收标准，不预生成固定分钟数的逐日必做任务。

## 命名规则

以后新增周计划时使用：

`第NN周_YYYY-MM-DD至YYYY-MM-DD_阶段主题`

每天的子文件夹使用：

`DayNN_YYYY-MM-DD_周X_当天主题`

每个每日子文件夹至少包含一个 `每日任务与记录.md`；代码、数据和截图可放在同一子文件夹的 `练习材料/` 中。
